Diskriminantas ir šaknys

Kas yra diskriminantas D? Kai sprendžiame lygtį ax²+bx+c = 0, sprendinių (šaknų) ieškome pagal formulę:

x₁ ir x₂ — tai tiesiog du taškai, kuriuose parabolė kerta Ox ašį. Jokios kitos paslapties čia nėra: sprendinių (šaknų) radimas = tų kirtimo su ašimi taškų radimas.
x = −b ± √D2a
kur D = b² − 4ac

Skaičius po šaknies ženklu (D) iš anksto pasako, ar sprendinių apskritai bus. Iš neigiamo skaičiaus šaknies ištraukti negalime — todėl kai D neigiamas, realių sprendinių nėra. Kai D lygus nuliui, „±“ dalis pradingsta ir lieka tik vienas sprendinys. Kai D teigiamas — turime du skirtingus sprendinius, nes „+“ ir „−“ duoda skirtingus taškus.

Kas yra viršūnė? Viršūnė — tai taškas, kuriame parabolė pakeičia kryptį: jei a > 0, tai žemiausias grafiko taškas (funkcija čia liaujasi mažėti ir pradeda didėti); jei a < 0 — tai aukščiausias taškas. Per viršūnę visada eina simetrijos ašis, dalinanti parabolę į dvi veidrodines puses.

Kodėl šaknų formulė susijusi su viršūnės radimu? Pažvelk dar kartą į formulę aukščiau: dalis −b2a (be „± √D“) — tai tiksliai viršūnės x koordinatė. O pačią formulę galima išskaidyti į du atskirus sprendinius:

x₁ = −b2a − √D2a
x₂ = −b2a + √D2a

Kadangi √D į formulę įsijungia su „±“, dydis D nulemia, kiek iš viso tų sprendinių (taigi ir kirtimo su Ox taškų) bus:

D > 0
dvi šaknys — abi vienodai (√D/2a) nutolusios nuo viršūnės x = −b/2a
D = 0
viena šaknis — liečia ašį
D < 0
šaknų nėra — ašies nekerta
D > 0
√D yra teigiamas skaičius, tad atėmus ir pridėjus jį prie −b2a gauname du skirtingus skaičius: x₁ = −b2a − √D2a ir x₂ = −b2a + √D2a.
D = 0
√D = √0 = 0, tad abu nariai formulėje virsta tuo pačiu: x₁ = x₂ = −b2a ± 0. Lieka tiesiog viršūnės x koordinatės formulė — jokio atskiro „šaknų traukimo“ nebereikia.
D < 0
Po šaknies ženklu lieka neigiamas skaičius. Realiųjų skaičių aibėje iš neigiamo skaičiaus šaknies ištraukti neįmanoma — √D tiesiog neegzistuoja. Todėl x₁ ir x₂ formulė neduoda jokio atsakymo: parabolė niekada nelygi nuliui.

Pačios šaknys yra simetriškos abipus viršūnės — viena nutolusi per atstumą √D2a į kairę, kita — lygiai tiek pat į dešinę. Todėl viršūnė visada atsiduria per vidurį tarp dviejų šaknų. O kai D = 0, tas „atstumas“ tampa nuliu — vienintelė šaknis tiesiog sutampa su viršūne.

Trečia perspektyva — šaknų (faktorizuota) forma. Kai žinai abi šaknis x₁ ir x₂, funkciją galima užrašyti dar ir taip: f(x) = a(x − x₁)(x − x₂). Paspausk mygtuką „a(x−x₁)(x−x₂)“ formulės juostoje viršuje ir pamatysi dabartinę funkciją šia forma (veikia tik kai D ≥ 0 — juk be realių šaknų nėra ko į skliaustus rašyti).

Išskleidus skliaustus a(x−x₁)(x−x₂) = a(x² − (x₁+x₂)x + x₁x₂) ir palyginus su ax²+bx+c, gaunamos Vieto formulės — tiesioginis ryšys tarp šaknų sumos/sandaugos ir koeficientų, visai be šaknies traukimo:

x₁ + x₂ = −ba
x₁ · x₂ = ca

Dabar (jei D ≥ 0): x₁ + x₂ = —, x₁ · x₂ = —.

Kita perspektyva — viršūnės forma. Tą pačią funkciją galima užrašyti kitaip: f(x) = a(x − m)² + n. Tai lygiai ta pati parabolė, tik dabar viršūnė — tai tiesiog koordinačių pora (m; n), kurią matai iš karto, be jokių skaičiavimų — nes reiškinys (x − m)² tampa mažiausias (lygus 0) būtent kai x = m.

Atkreipk dėmesį: prieš m formulėje visada stovi minusas — tai numatytasis (default) ženklas. Būtent čia mokiniai dažniausiai suklysta: jei viršūnė yra, tarkime, x = 3, formulėje reikės rašyti (x − 3), o jei viršūnė yra x = −3, reikės rašyti (x − (−3)) = (x + 3). Ženklas prieš m formulėje ir realaus m skaičiaus ženklas — ne tas pats dalykas.

Ryšys su bendrąja forma toks pat, kaip ir šaknų formulėje: m = −b2a, o n = f(m) — tiesiog funkcijos reikšmė viršūnės taške. Paspausk mygtuką „a(x−m)²+n“ formulės juostoje viršuje ir pamatysi, kaip dabartinė funkcija atrodo šia forma: (m; n) = (0; 0).

Iš kur atsiranda m ir n? (Kvadrato užbaigimas) Bendroji forma ax²+bx+c iš karto nepasako nei viršūnės, nei to, kiek šaknų bus — reikia skaičiuoti. Viršūnės forma a(x−m)²+n tai pasako iš karto. Štai kaip viena forma paverčiama kita:

1
f(x) = ax² + bx + c
Pradinė, bendroji forma.
2
f(x) = a(x² + bax) + c
Iš pirmų dviejų narių iškeliame a prieš skliaustus.
3
f(x) = a(x² + bax + b2a² − b2a²) + c
Skliaustuose pridedame ir iš karto atimame b2a² — suma nepasikeičia, bet dabar pirmieji trys nariai sudaro pilną kvadratą.
4
f(x) = a(x + b2a)² − a·b2a² + c
Pirmieji trys nariai suglaudžiami į (x + b2a)², likusi „− (b2a)²“ dalis padauginama iš a ir iškeliama už skliaustų.
5
f(x) = a(x − (−b2a))² + (c − b²4a)
Supaprastinę antrą narį (a·(b2a)² = b²4a) ir palyginę su a(x−m)²+n, matome, kas yra m ir n.
m = −b2a n = c − b²4a

Įdomus bonusas: kadangi D = b² − 4ac, tą patį n galima užrašyti ir taip: n = −D4a. Vadinasi, net viršūnės y koordinatė yra tiesiogiai susijusi su diskriminantu!

Praktikoje (kai a = 1) — greitosios daugybos formulė. Mokykliniuose uždaviniuose dažniausiai matysi būtent tokį atvejį, kai a = 1 — pvz., x² + 6x + 8. Raidžių čia tarsi nesimato, bet pirmasis narys jau yra x², tad patogiausia remtis pažįstama greitosios daugybos formule (a+b)² = a² + 2ab + b² (raidė „a“ čia — pačios formulės narys, ne mūsų koeficientas a).

1
x² + 6x + 8
Pirmasis narys — x². Tai tiksliai atitinka a² formulėje (a+b)², kai a = x. Vadinasi, rezultatas atrodys kaip (x + ...)².
2
2 · x · b = 6x
Pagal formulę antrasis narys turi būti 2ab. Kadangi a = x, lieka rasti b: iš 2xb = 6x gauname b = 3.
3
b² = 3² = 9
Kad susidarytų pilnas kvadratas, trečiasis narys turėtų būti 9. Bet mūsų lygtyje laisvasis narys — tik 8, taigi trūksta 1.
4
x² + 6x + 9 − 1
Nieko sudėtingo: „pasiskoliname“ 9, kad gautųsi pilnas kvadratas, o tą papildomai atsiradusį vienetą iš karto atimame, kad reikšmė nepasikeistų.
5
x² + 6x + 8 = (x + 3)² − 1
Pirmieji trys nariai — pilnas kvadratas (x + 3)². Lieka tik „− 1“.
m = −3 n = −1

Tai lygiai tas pats bendrasis metodas iš aukščiau — tik kai a = 1, viskas supaprastėja iki „pusė iš b, kvadratu, ir pasitikrinam su c“. Patikrinkime bendrąja formule: m = −b2a = −62 = −3, n = c − b²4a = 8 − 9 = −1 — sutampa!

D = b² − 4ac→dabar: D = 1

D > 0
Parabolė kerta x ašį dviejuose taškuose — lygtis turi dvi skirtingas realias šaknis.
D = 0
Parabolė liečia x ašį viename taške — lygtis turi vieną (dvigubą) šaknį.
D < 0
Parabolė visiškai nekerta x ašies — realių šaknų nėra.
